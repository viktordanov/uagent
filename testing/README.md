# Testing support

<!-- memoria:export id="summary" -->
The testing directory holds deterministic fixtures (captured runner output and event builders) and the generated mocks used by the unit tests.
<!-- /memoria:export -->

## Fixtures

`fixtures` builds deterministic test data: a fixed `T0`, `At(d)`, `Request()` and `RequestWith(fn)`, and event builders for a turn (`Turn`) and a tool call (`ToolRun`).
`RunnerOutput(name)` returns captured unreal-agent-runner stdout from `fixtures/runner/`, with local paths replaced by `/workspace` and `/state`:

| File | Run |
| --- | --- |
| `simple.jsonl` | Two parallel Bash calls, then the final answer `hello` |
| `parallel.jsonl` | Three sequential Bash calls over four turns, then `A; B` |
| `timeout.jsonl` | One long Bash call, killed by a timeout, with no answer |

Replace a fixture only with real runner output, and remove local paths before committing it.

## Mocks

`mocks/` is generated by mockery v3 from `.mockery.yaml` and is not committed. Run `go generate ./...` before `go test ./...`.
The domain tests build a harness around `MockPreflight`, `MockRunner`, and `MockRunStore` and set expectations with `EXPECT()`.
